# Demo-05B/C v3：政务驾驶舱风格优化

这版不是简单把上一版“做得更炫”，而是按公开的数字政府/城市大脑/教育驾驶舱案例重新调整信息架构。

## 主要变化

### 1. 从“普通网页表单”改为“驾驶舱”

采用：

```text
顶部标题与系统时钟
左：服务对象 / 任务接入
中：核心语音分析画面
右：智能研判 / 规范表达 / 后续接入
底：处理流水
```

这样更接近“一屏统览”的政务大屏逻辑。

### 2. 不再用 DeepSeek 式假“思考文字”

取消大段逐字假推理。
改成：

```text
当前分析阶段
+ 进度
+ 处理流水
+ 实际时频分析画面
```

更像业务系统的运行态势，而不是聊天机器人。

### 3. 15 秒过程仍保留，但明确是“演示流程”

流程约 15 秒：

```text
任务接入
音频质检
时频分析
语音特征提取
个性化语音库匹配
时序校验与拒识判断
规范中文结果生成
```

最终真实 API 约在 13.2 秒才发出，因此前面并没有拿到最终识别答案。

页面同时明确展示：

```text
模型实际耗时 xxx ms
```

避免把演示动画时间当作真实模型耗时。

### 4. 时频图不预先显示

选 WAV 时只解码音频。
点击识别后才计算并逐步显示简化 STFT 时频图：

```text
0% → 100%
```

扫描线同步移动。

### 5. 最终结果才逐字显示

真实 Runtime 返回后，`canonical_text` 才进入右侧“智能研判”区并逐字符显示。

## 覆盖

备份：

```powershell
Copy-Item demo\demo05_web\static demo\demo05_web\static_before_v3 -Recurse
```

将 ZIP 解压到 `papr_ssl` 根目录覆盖三个静态文件。

启动：

```powershell
python scripts\run_demo05_web.py
```

访问：

```text
http://127.0.0.1:7860
```

强制刷新：

```text
Ctrl + F5
```
