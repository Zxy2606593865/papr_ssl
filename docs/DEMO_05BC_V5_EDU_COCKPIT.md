# Demo-05B/C v5 — 特殊教育试点应用驾驶舱

这版不再继续单纯叠“科技特效”，而是把页面进一步改成：

```text
项目成果驾驶舱
+
AI语音工作台
+
应用闭环
```

## v5 的核心变化

### 1. 任务化

新增真实项目常见的“本次任务”区域：

```text
任务编号
服务对象
输入类型
数据来源
注册表达
个性化样本
当前状态
```

任务编号仅用于 Demo 本地展示。

### 2. 动态流程改为非匀速

不再每个阶段平均 2 秒。

新的约 14.8 秒节奏：

```text
任务接入                 0.85s
音频质量检查             1.20s
时频分析                 3.10s
表征提取                 2.70s
个性化语音库匹配         3.00s
时序校验                 1.80s
拒识判断                 1.00s
规范中文生成             1.15s
```

这样比匀速动画更自然。

### 3. 更细颗粒的流式处理流水

流水不再只有 7 条主阶段。

现在会展示十多条细分事件，例如：

```text
已接收王灏真实语音任务
正在读取音频文件与基础参数
输入检查完成：16000 Hz / 3.82 s
正在计算语音能量：RMS ... / Peak ...
正在生成真实录音的简化 STFT 时频结构
正在提取个性化语音表征
正在执行表征归一化与时序特征准备
正在加载王灏个性化语音记忆
个性化语音库已加载：5 项规范表达 / 10 条样本
正在执行候选规范表达匹配
正在执行时序特征校验
正在执行已注册 / 未注册表达拒识判断
正在提交最终个性化识别请求
```

其中采样率、时长、RMS、Peak、注册数量、样本数量都来自当前真实数据/前端计算。

### 4. 中央分析读数更真实

新增：

```text
分析帧
当前能量
频谱进度
候选空间
```

这些随真实 WAV 时频分析过程动态变化。

### 5. 应用闭环

右侧新增：

```text
特殊语音采集
→ 个性化理解
→ 规范中文转换
→ 标准语音输出
→ 智能学伴接入
```

前四步在 Demo 中根据真实流程亮起；
智能学伴保持“下一阶段”。

### 6. 研判结果更像业务结果

最后不只是出现一句中文，而是同时更新：

```text
规范中文
标准语音
智能学伴
```

状态。

## 安装

这是完整静态页面替换包。

建议先备份：

```powershell
Copy-Item demo\demo05_web\static `
  demo\demo05_web\static_before_v5 `
  -Recurse
```

将 ZIP 解压到 `papr_ssl` 根目录，覆盖：

```text
demo/demo05_web/static/index.html
demo/demo05_web/static/styles.css
demo/demo05_web/static/app.js
```

启动：

```powershell
python scripts\run_demo05_web.py
```

访问：

```text
http://127.0.0.1:7860
```

强制刷新：

```text
Ctrl + F5
```

## 仍然保持的真实性边界

- 约 15 秒是展示流程，不是模型真实计算时间；
- 最终 Runtime 请求仍在末段发出；
- Runtime 返回后才显示最终规范中文；
- 时频分析图来自真实 WAV 的简化 STFT；
- RMS / Peak / 采样率 / 时长均来自真实音频；
- 不声称当前模型是流式 ASR；
- 不展示内部 Intent ID 和未经校准的置信度。
