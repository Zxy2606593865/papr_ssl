# Demo-05B/C v7 — 一屏规整版

这版只做视觉和布局收敛，不改 v6 的功能逻辑。

## 主要修改

### 1. 弱化顶部 5 个概况模块

顶部：

- 试点对象
- 已注册规范表达
- 个性化样本
- 系统运行状态
- 演示流程

仍保留，但从“主视觉卡片”降级为“概况条”。

调整包括：

- 高度压缩；
- 背景更平；
- 边框更弱；
- 数字不再过度发光；
- 整体透明度稍降。

它们现在只是辅助信息，不再抢中央分析区和运行流水的视觉重点。

### 2. 运行处理流水进一步放大

`运行处理流水`：

- 字号明显增大；
- 时间 12px；
- 处理事件 13px；
- 行高增大；
- 时间 / 处理事件 / 状态 三列宽度重新调整；
- 区域占中央列高度约 40% 左右。

### 3. 整体字号提升

整体正文、按钮、任务列表、研判状态、闭环状态均提升 1~3px。

目标不是“大字报”，而是让 1080P 大屏 / 投影上更容易看。

### 4. 一屏规整

桌面端采用固定的一屏 Grid：

```text
顶部标题
概况条
主驾驶舱
页脚
```

主驾驶舱三列严格同高：

```text
左：本次任务 / 原始语音 / 演示控制
中：双图分析 / 大型运行流水
右：智能研判 / 应用闭环
```

各列内部也使用固定比例 Grid，对齐上下边界。

### 5. 1080P 优先

主要针对：

```text
1920×1080
2560×1440
```

这种汇报 / 投影 / 大屏环境。

浏览器建议：

```text
缩放 100%
F11 全屏
```

## 安装

这是 **v6 的纯 CSS 升级包**。

覆盖：

```text
demo/demo05_web/static/styles.css
```

即可。

建议先备份：

```powershell
Copy-Item demo\demo05_web\static\styles.css `
  demo\demo05_web\static\styles_v6_backup.css
```

然后覆盖新样式。

启动仍然是：

```powershell
python scripts\run_demo05_web.py
```

进入页面后：

```text
Ctrl + F5
```

建议最终甲方展示时直接：

```text
F11
```

进入浏览器全屏。
